

theory:

a := [8]int

массив: непрерывная область(блок) в памяти в котором последовательно располагаются ячейки (ячейка = элемент массива).

-- a[i] = доступ к элементу массива по индексу
complexity = O(1)
// т.к. у всех элементов массива одинаковый тип
поэтому: memory address of i-того элемента вычисляется "примерно так":
(p.s. в реальных языках программирования другое более сложное вычисление, но все равно за "константное" время.)
addr(a[i]) = addr(a[0]) + offset(i)
offset(i) = i*(array_type_alloc_size) 
// p.s. addr(a[0]) = адрес начального элемента массива, 
// p.s. array_type_alloc_size = allocation size for type of array (example: for type int = 4 bytes)

-- len(array) = длина массива (size of array) (количество элементов массива).
complexity = O(1)
// т.к. у массива Фиксированная длина: указывается при создании массива (known at compile time, хранится в metadata) и не изменяется.
